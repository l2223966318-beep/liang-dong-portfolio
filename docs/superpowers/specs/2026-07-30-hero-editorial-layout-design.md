# Hero 编辑式信息区优化

## 目标

根据浏览器批注，对作品集首页首屏做三项局部调整：

1. 左上署名由“LD / 26”改为“梁栋 / 26”。
2. 顶部主导航移除“关于”，保留“项目 / AIGC / 研究”与“联系我”。
3. 优化“让内容成为增长资产”信息区的排版，使标题、能力描述、行动入口和城市年份信息形成清晰层级。

## 设计方案

采用编辑式排版方向，不改变现有字体、红蓝主色、首屏视频、英文主标题和下一章节入口。

桌面端信息区使用明确的纵向节奏：

- 中文主标题作为信息区的第一视觉层级。
- “内容策略 × 增长运营 × 影像与 AIGC”作为独立信息行，通过间距和细分隔线组织，不使用胶囊标签。
- “查看项目”作为独立底行，保留箭头与红色强调线。
- “CHENGDU · 2026”与行动入口在同一视觉基线内组织，不再压在主标题附近。
- 信息区宽度受控，不侵入右侧视频主体或底部 Profile 预告区域。

移动端保持相同信息顺序，改为单列堆叠；标题、能力行和行动入口均不得造成横向溢出。

## 代码范围

- `src/components/Hero.tsx`
  - 更新署名文字。
  - 调整城市年份信息在 Hero 信息区中的语义位置。
- `src/components/AppShell.tsx`
  - 移除顶部“关于”导航项。
- `src/styles/shell-hero.css`
  - 调整 Hero 信息区的尺寸、留白、分隔与响应式规则。
- 对应组件测试与端到端测试
  - 验证署名和导航内容。
  - 验证桌面、手机端无横向溢出。

## 验收标准

- 首屏显示“梁栋 / 26”，不再显示“LD / 26”。
- 顶部主导航不再包含“关于”，其他入口保持可用。
- 1227×624、1700×1000 和 390×844 视口下，信息区不与主标题、视频控制或 Profile 预告重叠。
- 页面无横向滚动、无控制台错误，现有项目与案例页行为不受影响。
